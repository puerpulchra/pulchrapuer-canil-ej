# Fase 3 · Backend (Supabase)
Plugin Supabase instalado; falta ligar o conector Supabase e criar o projeto.
Tabelas previstas: cães (ficha, estado), visitas (data, hora, pessoas, cão), pedidos da loja, serviços, mensagens.
Regras: RLS ligada em todas as tabelas; o público só lê cães e serviços; visitas e pedidos só inserem.
Usar as skills `supabase` e `supabase-postgres-best-practices`.
